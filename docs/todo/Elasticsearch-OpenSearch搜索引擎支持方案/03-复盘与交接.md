## 1. 最终结论

本轮已完成实施方案、OpenSpec artifacts、代码实现、双语 README、最终验证、Docker 真实服务 E2E 和 GF Review。GoFrame 新增搜索/文档引擎抽象 `database/gsearch`，并通过 `contrib/nosql/elasticsearch` 和 `contrib/nosql/opensearch` 分别接入官方客户端。

核心决策是避免混淆 SQL ORM 与搜索引擎：`database/gdb` 不参与实现，`contrib/drivers/*` 不新增 ES/OpenSearch。当前 active OpenSpec change 仍未归档，需在用户确认后按项目流程执行 archive。

## 3. 关键决策回顾

| D-ID | 决策 | 为什么这样做 | 依据来源 | 结果是否符合预期 | 后续注意 |
|---|---|---|---|---|---|
| D-001 | 不实现为 `gdb.Driver` | `gdb` 公共接口和内部链路强绑定 SQL/`database/sql` | GitNexus + `database/gdb/gdb.go` | 是 | 禁止触碰 DAO 生成链 |
| D-002 | 新增 `database/gsearch` | root 轻抽象 + contrib 重依赖符合现有模式 | `database/gredis` / `gcfg` / `gsvc` | 是 | 包名需 maintainer 最终确认 |
| D-003 | Elasticsearch 与 OpenSearch 分 adapter | 官方客户端、兼容矩阵、认证和 typed API 已分叉 | 官方文档 + DeepWiki + subagent | 是 | 不承诺互通 |
| D-004 | root 不暴露 typed API | typed API 变化快且两个项目不同 | Elastic/OpenSearch docs | 是 | 保留 `Perform` 和 `Client()` |
| D-005 | Search/Bulk 响应显式表达 partial/error | 搜索成功语义不等于 HTTP 2xx | REST/Bulk docs | 是 | 测试必须覆盖 |
| D-006 | 专利只作风险提醒 | 未发现禁止 REST adapter 的确定证据 | Google Patents / Justia 检索 | 是 | 高级功能前做法律审查 |

## 4. 踩坑与修复

| PIT-ID | 问题 | 发现方式 | 修复方式 | 后续预防 |
|---|---|---|---|---|
| PIT-001 | 容易把 ES/OpenSearch 误认为 `gdb` driver | 源码调用链分析 | 明确排除 `database/gdb` 和 `contrib/drivers` | 实施前复查候选目标 |
| PIT-002 | Redis 的单默认 adapter function 不适合双引擎并存 | `gredis.RegisterAdapterFunc` 分析 | 方案改为按 `EngineType` 注册 factory | T-002 测试并存导入 |
| PIT-003 | `rg es` 会大量误命中普通变量名和 swagger 资产 | 源码搜索 | 使用完整关键字并人工核对 | 证据表写明无真实实现 |
| PIT-004 | OpenSpec 工具输出与文件系统 active change 视图不一致 | `openspec list --json` 与 `find` 差异 | T-001 前置确认归属 | 不直接进入代码实现 |
| PIT-005 | Elastic v9 Go 1.24+ 与 root Go 1.23 冲突 | 官方 docs + go.mod 校准 | root 不依赖官方 SDK | contrib 版本决策前复查 |
| PIT-006 | OpenSearch v4/v5 Go 版本不适合当前 Go 1.23 module | `go list -m -json` | 首版选择 `opensearch-go/v3 v3.1.0` | 未来升级 SDK major 前复查 Go 版本策略 |
| PIT-007 | Docker env value 带空格时必须加引号 | 首次 `docker run` exit 125 | 使用 `-e "ES_JAVA_OPTS=-Xms512m -Xmx512m"` 和 `-e "OPENSEARCH_JAVA_OPTS=-Xms512m -Xmx512m"` | 复制 Docker E2E 命令时保留引号 |
| PIT-008 | Docker Hub 拉取可能出现 TLS handshake timeout | OpenSearch 首次拉取失败 | 重试同一镜像后成功 | 不把网络拉取失败误判为代码失败，保留日志 |

### 6.2 配置说明

| 配置 | 推荐值 | 注意事项 |
|---|---|---|
| `search.default.type` | `elasticsearch` 或 `opensearch` | 必填，使用 named const 解析 |
| `search.default.addresses` | `["https://localhost:9200"]` | 不要在文档硬编码生产地址 |
| `search.default.username/password` | 空或测试值 | 示例必须标注仅测试 |
| `search.default.apiKey` | 空 | Elastic 常用，需避免泄露 |
| `search.default.aws.*` | 空 | OpenSearch adapter 扩展，不进入 root |

### 6.3 日志与排查

| 场景 | 查看位置 | 判断方法 |
|---|---|---|
| adapter 未导入 | `gsearch.New` error | 应提示导入 `contrib/nosql/elasticsearch` 或 `opensearch` |
| 产品类型不匹配 | adapter `Ping/Info` | 应返回明确 product mismatch |
| Bulk 局部失败 | `BulkResponse.Items` | HTTP 2xx 仍需检查 item error |
| Search 局部失败 | `SearchResponse.Shards/TimedOut` | partial failure 不应被吞掉 |
| 配置未读取 | `gins.Search` | 检查 `search.<group>` 节点和 group name |
